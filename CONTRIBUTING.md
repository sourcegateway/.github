# Contributing

Thanks for your interest in contributing!

Source Gateway is part of the Podplane ecosystem of open source projects. You can learn more about Podplane at the official website: https://podplane.dev

If you've found a bug or have a feature request, please file a GitHub Issue at https://github.com/sourcegateway/sourcegateway/issues

If you'd like to discuss Source Gateway or Podplane in general, please join the community forum at https://forum.podplane.dev

We also greatly appreciate code contributions! Opening a Pull Request requires a quick onboarding process — full instructions can be found here: https://contribute.podplane.dev
